# تطبيق آيفون وآيباد

غلاف أصلي بـ Capacitor يفتح الموقع نفسه، ويضيف إليه ما لا يقدر عليه المتصفّح:
إشعارات من آبل، واهتزازًا خفيفًا عند الإجابة، ومشاركة النتيجة من نافذة النظام،
وشريط حالة يتبع المظهر، وشاشة انطلاق تنتظر استيقاظ الخادم.

كل تعديل على الموقع يصل إلى التطبيق فورًا بلا نسخة جديدة. النسخة الجديدة لا
تلزم إلا إذا تغيّر شيء داخل مجلد `mobile/` نفسه.

## كيف يعمل

| الملف | دوره |
|---|---|
| `www/index.html` | شاشة الانطلاق المحلية: تسأل `/health` حتى يجيب الخادم ثم تنتقل إليه، وتشرح الحال إن طال الانتظار أو انقطعت الشبكة. وهي أيضًا صفحة الخطأ إن تعذّر تحميل الموقع لاحقًا |
| `capacitor.config.json` | المعرّف `com.saudalh.lotg`، والنطاق المسموح بفتحه داخل التطبيق، ووسم `LOTGApp/1` الذي يعرف به الخادمُ التطبيقَ |
| `ios/` | مشروع Xcode. الأيقونة وشاشة البدء والصلاحيات والاتجاهات (عمودي على آيفون، وكل الاتجاهات على آيباد) |
| `ci/signing.py` | التوقيع على خادم البناء بلا ماك (انظر أدناه) |
| `store-screenshots/` | لقطات المتجر بالمقاسين المطلوبين: آيفون ٦٫٩ بوصة (1290×2796) وآيباد ١٣ بوصة (2048×2732) |

والصفحة تعرف أنها داخل التطبيق من جسر Capacitor (`NATIVE` في `ui.py`)، فتستعمل
إشعارات آبل بدل إشعارات الويب، ولا تسجّل عامل الخدمة.

### التوقيع بلا ماك

كل بناء ينشئ عبر واجهة App Store Connect شهادة توزيع مؤقّتة وملف تعريف للمتجر،
ويوقّع بهما ويرفع إلى TestFlight، ثم يلغيهما. فلا شهادات تُحفظ في الأسرار، ولا
حاجة إلى جهاز مسجّل. والتطبيقات المرفوعة لا تتأثّر بإلغاء الشهادة لأن آبل تعيد
توقيعها بنفسها. وإن انقطع بناءٌ قبل التنظيف، ألغى البناء التالي بقاياه قبل أن
يبدأ، فلا يُبلغ حدّ الشهادات الثلاث.

## الإعداد مرة واحدة

### ١. مفتاح واجهة App Store Connect (للبناء والرفع)

1. [App Store Connect](https://appstoreconnect.apple.com) ← Users and Access ← Integrations ← App Store Connect API ← Team Keys.
2. أنشئ مفتاحًا بدور **Admin** (الدور الأدنى لا يكفي لإنشاء الشهادات)، ونزّل ملف ‎`.p8`. يُنزَّل مرة واحدة فقط.
3. احفظ **Key ID** و **Issuer ID** الظاهرين في الصفحة نفسها.

### ٢. أسرار المستودع في GitHub

Settings ← Secrets and variables ← Actions ← New repository secret:

| السرّ | القيمة |
|---|---|
| `APPLE_TEAM_ID` | من [بوّابة المطوّر](https://developer.apple.com/account) ← Membership details ← Team ID |
| `ASC_KEY_ID` | Key ID من الخطوة ١ |
| `ASC_ISSUER_ID` | Issuer ID من الخطوة ١ |
| `ASC_KEY_P8` | افتح ملف ‎`.p8`‎ بمحرّر نصوص وانسخ محتواه كاملًا بسطوره |

### ٣. معرّف التطبيق وسجلّه في المتجر

1. بوّابة المطوّر ← Certificates, Identifiers & Profiles ← Identifiers ← ➕ ← App IDs ← App.
   الوصف `LOTG`، والمعرّف **Explicit** بقيمة `com.saudalh.lotg`، وفعّل **Push Notifications**.
   (البناء الأول يسجّله تلقائيًا إن نسيت، لكن الخطوة التالية تحتاجه قبل ذلك.)
2. App Store Connect ← Apps ← ➕ ← New App: المنصّة iOS، الاسم **قوانين اللعبة**،
   اللغة الأساسية العربية، المعرّف `com.saudalh.lotg`، و SKU أي نصّ مثل `lotg`.

### ٤. مفتاح الإشعارات على ريندر

1. بوّابة المطوّر ← Keys ← ➕ ← فعّل **Apple Push Notifications service (APNs)** ← نزّل ملف ‎`.p8`.
2. في لوحة ريندر ← الخدمة ← Environment:

| المتغيّر | القيمة |
|---|---|
| `APNS_KEY` | محتوى ملف ‎`.p8`‎ للإشعارات كاملًا |
| `APNS_KEY_ID` | معرّف هذا المفتاح |
| `APNS_TEAM_ID` | معرّف الفريق نفسه |
| `CONTACT_EMAIL` | بريد التواصل الذي يظهر في صفحتي الخصوصية والدعم |

مفتاح الإشعارات غير مفتاح الواجهة في الخطوة ١، ويمكن أن يكون واحدًا يجمع الخدمتين،
لكن فصلهما أسلم.

### ٥. الخادم قبل التطبيق

التطبيق يعتمد على تغييرات في الخادم (`/health` يقبل سؤال التطبيق، ومسارات إشعارات
آبل، وصفحتا الخصوصية والدعم). فادفع التغييرات إلى `main` وانتظر انتهاء النشر على
ريندر قبل أول بناء.

ومجدول الإشعارات الذي ينادي `/api/push/dispatch` كل ربع ساعة يُبقي الخادم مستيقظًا
أيضًا، فلا يرى مراجع آبل ولا المستخدمون شاشة الانتظار إلا نادرًا.

## البناء والرفع

GitHub ← Actions ← **iOS TestFlight** ← Run workflow، واكتب رقم الإصدار (مثل `1.0.0`).
يأخذ البناء نحو ١٥ دقيقة، ثم يظهر في App Store Connect ← TestFlight بعد معالجته.

رقم البناء يتزايد تلقائيًا مع كل تشغيل. ورقم الإصدار يُرفع يدويًا عند كل نسخة
جديدة للمتجر (`1.0.1`، `1.1.0`…).

### التجربة على جوالك

1. ثبّت تطبيق **TestFlight** من آب ستور.
2. App Store Connect ← التطبيق ← TestFlight ← Internal Testing ← أضف نفسك.
3. تصلك دعوة، ثبّت منها التطبيق.

جرّب: الدخول، وسؤال اليوم (اهتزاز عند الإجابة)، وتفعيل الإشعار من «الحساب» ثم
«إرسال تجربة»، ومشاركة نتيجة اختبار، وتبديل المظهر (لون شريط الحالة يتبعه).

## الإرسال للمراجعة

ما يطلبه المتجر، وما يُلصق في كل حقل، في [`STORE.md`](STORE.md).

## إن اعترضت آبل على صفحات الكتاب

اضبط `APP_HIDE_BOOK=1` في ريندر. تختفي أزرار صور الصفحات من التطبيق وحده فورًا،
ويرفض الخادم طلبها منه، وتبقى في الموقع كما هي. لا يلزم بناء جديد.

## تغيير رابط الخادم

الرابط مكتوب في موضعين: `SITE` في `www/index.html`، و `server.allowNavigation`
في `capacitor.config.json`. غيّرهما معًا ثم ابنِ نسخة جديدة.

## التطوير على ماك (اختياري)

```bash
cd mobile
npm ci
npx cap sync ios
npx cap open ios      # يفتح Xcode، واختر فريقك في Signing & Capabilities
```
